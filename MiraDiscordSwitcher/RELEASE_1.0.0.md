# Mira Discord Switcher 1.0.0

Initial public release of Mira Discord Switcher.

## What it does

Mira Discord Switcher keeps multiple Discord accounts available in one Windows application window. Add another session with **+ Add**, sign in once, and move between remembered accounts with tabs instead of repeatedly logging in and out.

## Included in 1.0.0

- Multiple independent Discord sessions in one window.
- Persistent per-session login state.
- Tab-based session switching.
- **+ Add**, **Reload**, **Rename**, and **Remove** controls.
- Windows taskbar notification badges using counts reported by Discord.
- Regular Discord functionality remains available inside each session.
- **X** exits the application; minimize only minimizes the window.

## Requirements

- 64-bit Windows 10 or Windows 11.
- Network access to Discord.
