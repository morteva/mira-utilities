MIRA CURSOR PACK 1.0.0
Pearl white. Soft glow. A tiny companion dot.
Built by Mira with Mia for This Is Beside.

Windows 10 and Windows 11. All 17 cursor roles included.
The normal arrow matches the approved 50% website cursor.
Open showcase.html to see the shapes enlarged.

INSTALL
1. Extract the entire ZIP to a folder.
2. Double-click Install.vbs.
3. Choose whether to keep your current Busy cursor.
4. In Mouse Properties > Pointers, select Mira Cursor Pack and click Apply.

The installer copies only this pack's cursor files into your Local AppData,
registers a per-user scheme, and opens Mouse Properties. Your current setup
stays active until YOU click Apply. No administrator access or network needed.
It saves your prior setup as Before Mira Cursor Pack the first time you install.

IF WINDOWS SCRIPT HOST IS DISABLED
You can still use the pack manually: open Mouse Properties > Pointers,
select a role, click Browse, and choose the matching .cur file (Wait uses .ani).
Use Save As to save the scheme as Mira Cursor Pack. Keep the folder afterward.
Do not disable your organization's security settings to run this installer.

SWITCH BACK
Choose Before Mira Cursor Pack, or your previous scheme, and click Apply.
Once another scheme is active, Delete the Mira Cursor Pack scheme in the panel
and remove %LOCALAPPDATA%\MiraCursorPack if you want to remove the installed files.

The Busy animation is a 12-frame pearl ring. Working In Background is static.
Cursor sizing follows Windows display scaling. The PNG showcase is enlarged,
not the installed size. This download does not install a background program.
